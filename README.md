# ZinkLab Portfolio

Static, single-page portfolio for ZinkLab. No build step.

- `index.html` – the whole site (HTML, CSS, JS)
- `images/` – logo, landing-page previews and poster artwork (referenced by filename)

## Deploy

Push this folder to a GitHub repository and import it in Vercel
(Framework Preset: **Other**, no build command, no output directory).

## Replacing images

Upload a new file to `images/` with exactly the same (case-sensitive) name and extension.
See `SETUP-GUIDE-BN.md` for the full list of filenames.
